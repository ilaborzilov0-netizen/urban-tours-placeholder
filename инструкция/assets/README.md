# Демозапись первого аудиоякоря

На /инструкция/ первым треком выбран **«Всё происходит»**.
Плеер ожидает файл `/инструкция/assets/vsyo-proiskhodit-demo-10s.mp3`.

Файл — короткий 10-секундный фрагмент, а не полная платная запись. Выдержка подготовлена из предоставленного оригинала; до помещения MP3 в эту папку проигрыватель на сайте не сможет его запустить.

Не публикуйте здесь 4:55 полной записи — только демофрагмент.
