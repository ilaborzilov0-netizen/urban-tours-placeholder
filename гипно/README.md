# Три дизайна гипноза — 990 ₽

- `/гипно/01/` — чёрно-золотой маятник
- `/гипно/02/` — оптическая спираль
- `/гипно/03/` — аудиопогружение в наушниках

Все лендинги статические, адаптивные и используют общие `assets/main.css` и `assets/main.js`. Кнопки показывают честное окно о статусе подключения оплаты, **денег не принимают**. Перед включением платежей необходимы подтверждённый аудиосеанс, тариф 990 ₽ на действующем платёжном сервере, выдача файла после оплаты и тест реальной оплаты. **Это репозиторий `borzilov-site`, который по последнему коммиту обозначен как legacy; сам по себе пуш в него не публикует страницы на `marafon-metod.ru`.**

Движения маятника и спирали можно остановить, поддерживается системный режим уменьшения анимаций.
